# 项目架构笔记

## 技术选型与理由
- 前端：React 18 + Vite 5 + TypeScript（精确锁定版本，提交 package-lock），手写 hash 路由，不引入组件库/状态管理库。
- 后端：零依赖原生 `node:http`，不引入任何 npm 依赖。
- 前端测试：Vitest 2 + @testing-library/react（jsdom，单 worker 池）；后端测试：`node --test`。
- 会话：服务端持久化 session + HttpOnly cookie（`session`），前端通过 `GET /api/auth/session` 读取。
