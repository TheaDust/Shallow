# 候选构建复用实施方案

## 目标与范围

控制器执行安装、构建和应用启停；Builder 通过本地 MCP 的 `prepare` / `stop` 使用自测实例。Judge 使用同一份已核验产物启动自己的实例。构建凭据仅存控制器内存和私有运行日志，Builder 回执不参与缓存判定。

## 实施顺序与职责

1. `candidate-runtime.ts`：在运行目录维护一个应用副本和一份构建记录；对输出目录的应用文件计算内容摘要（包含新文件与被 Git 忽略的业务文件，排除根 `.git` / `.arc` 与依赖目录）。复制前后复核，避免复制过程中源码变化。副本不包含控制器或 Judge 数据。
2. 安装仅复用当前运行中控制器建立的状态；依赖声明、锁文件、npm 配置、运行环境和安装命令参与依赖键。本地依赖或安装生命周期脚本存在时，应用输入变化也使安装失效。依赖缺失时重新安装。重新准备时清理旧副本的应用文件，保留有效依赖，避免旧产物残留。
3. 构建后冻结副本文件摘要；启动、停止与接受前检查副本及原始候选。应用运行数据使用合同注入的 `SHALLOW_DATA_DIR`，位于副本之外，不参与应用摘要。该合同不提供测试数据重置或多用户隔离。
4. `candidate-mcp.ts` 与 SDK 接入：仅暴露固定的准备和停止能力，不接受目录、命令、文件内容或验收参数。每次 Builder 调用开放工具，结束/取消时关闭准入、等待在途准备并停止自测实例；Judge 执行期间拒绝工具调用。
5. `pipeline.ts` / `final-verifier.ts` / `index.ts`：生产共用候选服务；报告关联候选、构建和实例 ID；准备失败进入现有修复梯子，候选在验收期间变化则禁止接受；回滚后按实际文件重新准备。最终交付保留安装/构建/启动/smoke 语义并复用匹配的准备结果；交付入口与完成前核对接受版本的输入摘要，防止迟到写入被一次新构建掩盖。
6. Builder 文案、事件类型、中文日志、README 与路线图同步说明新的调用顺序、文件范围、数据目录和保证边界。

## 验证

- 实际文件与命令 fixture：一次准备供自测与 Judge 使用；源码、新建文件、产物、依赖输入变化；删除源码不残留旧产物；首次及失败安装；构建失败不可复用。
- 应用实例 fixture：旧进程占端口、实例停止释放端口；准备过程中取消，迟到调用不可启动服务；验收中原目录或副本变化不能接受。
- MCP 协议与 SDK 配置/连接/清理检查；baseline 无此工具时保持原行为。
- Pipeline 接受、修复、回滚、最终交付与候选证据关联；执行 `npm run test:all`。

## 边界

私有副本与摘要不等于 OS 沙箱，不能阻止同用户任意进程访问。安装/构建脚本仍由 Builder 决定，控制器验证命令结果与输入/产物关联，不证明构建脚本语义正确。候选服务不读取官方测试，不向 Planner/Runner 传递源码；仅在本轮运行复用，不建立跨运行缓存。

应用文件当前只接受普通文件和目录，符号链接/junction 被拒绝；依赖目录属于控制器安装状态，用文件路径、大小、mtime、ctime、mode、inode 和链接目标检查通常的变化，而非逐次对全部依赖内容散列。该检测不提供对同用户恶意篡改文件系统元数据的保证。源文件和产物使用 SHA-256 内容摘要。

端口启动前必须空闲，已占用端口不会被当作就绪或自动杀掉；控制器追踪启动子进程、检查验收期间退出及停止后的端口释放。启动前端口检查与实际应用 bind 不是 OS 原子操作；不承诺抵抗同机恶意进程竞争端口。清理继承现有 Windows taskkill / POSIX 进程组机制。

缓存位于私有运行目录，包含安装生成的文件及生产构建；输出仓库继续保存 Builder 源码，平台交付时按原合同构建。迁移现有应用时需让持久化文件使用 `SHALLOW_DATA_DIR`；未设置时仍须支持自身缺省路径。应用运行期间在源码树写数据会使验收失效。

## 2026-09-08 验证结果

Windows 上 `npm run test:all` 通过：typecheck 正常，单元/集成 243 项通过、2 项跳过，独立 Chromium 浏览器测试 5 项通过。跳过项是显式 opt-in 的真实模型凭证冒烟与 POSIX 专用进程测试。

`test/candidate-runtime.test.ts` 的 20 个场景覆盖构建复用、依赖失效、迟到写入、准备取消、旧进程占端口、实际 MCP 客户端与 SDK 生命周期、以及验收/提交/交付阶段的变更拦截。实际命令 fixture 验证自测、Judge 和最终 Chromium smoke 共用一次安装与构建；这证明重复工作已消除，不代表已测得真实模型任务的端到端提速比例。
