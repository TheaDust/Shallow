# 行动：实现当前模块

1. 本工作包包含一个完整模块或相互依赖的模块组。检查现有项目，结合本次全部需求、场景与种子数据，统一实现模块内的数据模型、接口和界面；按模块内部依赖组织工作。
2. 延续同一会话中已完成的实现。按需核对相关代码；已有 ARCHITECTURE.md 可用于定位，但需求与平台合同优先，当前实现以代码核对。
3. 实现完整业务链路与需求明确要求的输入校验、状态及持久化。不要为某个示例数据或测试定位器实现特例。
4. 做必要的编译或开发检查；需要浏览器时按自测约定执行一次关键路径。将尚未解决的问题写进简短回执。
5. 仅当公共接口或数据约定发生重要变化时简短更新 ARCHITECTURE.md。文档记录服务于后续开发，不要求固定结构或完整复述实现。
